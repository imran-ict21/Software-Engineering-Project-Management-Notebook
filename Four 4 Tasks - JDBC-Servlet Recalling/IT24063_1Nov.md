### 3.1 Prime Number Concept

A prime number is a natural number greater than 1 that has exactly two
distinct positive divisors: 1 and itself.

Examples: `2, 3, 5, 7, 11, 13, 17, 19`.

The n-th prime number means the prime number at position `n` in the
ordered sequence of prime numbers.

    Input (n)   n-th prime number
  ----------- -------------------
            1                   2
            2                   3
            3                   5
            4                   7
            5                  11
           10                  29
          250                1583

### 3.2 Prime Number Calculation

The Java method `isPrime()` checks whether a number is prime. The method
`findNthPrime()` counts prime numbers until it reaches the requested
position.

**Source file: `NthPrimeNumber.java`**

``` java
import java.util.Scanner;

public class NthPrimeNumber {

    // Returns true if the given number is prime.
    public static boolean isPrime(int number) {
        if (number < 2) {
            return false;
        }

        // It is sufficient to check divisors up to the square root.
        for (int i = 2; i <= Math.sqrt(number); i++) {
            if (number % i == 0) {
                return false;
            }
        }

        return true;
    }

    // Finds and returns the n-th prime number.
    public static int findNthPrime(int n) {
        if (n < 1) {
            throw new IllegalArgumentException("N must be a positive integer.");
        }

        int count = 0;
        int number = 1;

        while (count < n) {
            number++;

            if (isPrime(number)) {
                count++;
            }
        }

        return number;
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter the value of N: ");
        int n = scanner.nextInt();

        int result = findNthPrime(n);

        System.out.println("The " + n + "-th prime number is: " + result);

        scanner.close();
    }
}
```

### 3.5 JDBC Database Connection and Insertion

JDBC (Java Database Connectivity) is a Java API that allows Java
applications to connect to relational databases, execute SQL statements,
and retrieve results.

The example below uses MySQL and the MySQL Connector/J driver. Update
the database username and password according to the local MySQL
configuration.

**Source file: `PrimeNumberJDBC.java`**

``` java
import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.PreparedStatement;
import java.sql.ResultSet;
import java.sql.SQLException;
import java.util.Scanner;

public class PrimeNumberJDBC {

    // Update these values according to your MySQL configuration.
    private static final String URL =
            "jdbc:mysql://localhost:3306/prime_lab";
    private static final String USER = "root";
    private static final String PASSWORD = "YOUR_MYSQL_PASSWORD";

    // Checks whether a number is prime.
    public static boolean isPrime(int number) {
        if (number < 2) {
            return false;
        }

        for (int i = 2; i <= Math.sqrt(number); i++) {
            if (number % i == 0) {
                return false;
            }
        }

        return true;
    }

    // Calculates the n-th prime number.
    public static int findNthPrime(int n) {
        if (n < 1) {
            throw new IllegalArgumentException("N must be positive.");
        }

        int count = 0;
        int number = 1;

        while (count < n) {
            number++;

            if (isPrime(number)) {
                count++;
            }
        }

        return number;
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter the value of N: ");
        int n = scanner.nextInt();

        int prime = findNthPrime(n);
        System.out.println("The " + n + "-th prime number is: " + prime);

        String insertSQL =
                "INSERT INTO imran_hossen_prime (input_n, prime_number) VALUES (?, ?)";

        String selectSQL =
                "SELECT id, input_n, prime_number, created_at " +
                "FROM imran_hossen_prime ORDER BY id DESC LIMIT 1";

        try (Connection connection =
                     DriverManager.getConnection(URL, USER, PASSWORD)) {

            System.out.println("Database connection successful!");

            // Insert the input and calculated prime number.
            try (PreparedStatement statement =
                         connection.prepareStatement(insertSQL)) {

                statement.setInt(1, n);
                statement.setInt(2, prime);

                int rowsInserted = statement.executeUpdate();
                System.out.println(rowsInserted + " record inserted successfully.");
            }

            // Retrieve and display the latest saved record.
            try (PreparedStatement statement =
                         connection.prepareStatement(selectSQL);
                 ResultSet resultSet = statement.executeQuery()) {

                System.out.println("\nRetrieved Database Record:");

                if (resultSet.next()) {
                    System.out.println("ID: " + resultSet.getInt("id"));
                    System.out.println("Input N: " + resultSet.getInt("input_n"));
                    System.out.println("Prime Number: " +
                            resultSet.getInt("prime_number"));
                    System.out.println("Created At: " +
                            resultSet.getTimestamp("created_at"));
                }
            }

        } catch (SQLException e) {
            System.out.println("Database operation failed: " + e.getMessage());
            e.printStackTrace();
        } finally {
            scanner.close();
        }
    }
}
```

## 5. Task 4: Browser-Based Primality Testing Using Java Servlet

**Marks: 6**

### Objective

To develop a Java Servlet that receives an integer from a browser form,
checks whether the number is prime, and displays the result in the
browser through Apache Tomcat.

### 5.1 How It Works

1.  The user opens the web application in a browser.
2.  The user enters an integer in the input field.
3.  The browser sends the value to the servlet using an HTTP GET
    request.
4.  The servlet validates the input and checks primality.
5.  The servlet returns an HTML response containing the result.

### 5.2 HTML Input Page

### 5.3 Java Servlet Source Code

**Source file: `PrimeServlet.java`**

> This code uses the Jakarta Servlet API for Tomcat 10 or later. For
> Tomcat 9, use the `javax.servlet` imports and a compatible Servlet API
> dependency instead.

``` java
import jakarta.servlet.ServletException;
import jakarta.servlet.annotation.WebServlet;
import jakarta.servlet.http.HttpServlet;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;

import java.io.IOException;
import java.io.PrintWriter;

@WebServlet("/prime-check")
public class PrimeServlet extends HttpServlet {

    // Checks whether a number is prime.
    private boolean isPrime(int number) {
        if (number < 2) {
            return false;
        }

        for (int i = 2; i <= Math.sqrt(number); i++) {
            if (number % i == 0) {
                return false;
            }
        }

        return true;
    }

    // Handles the form submission from the browser.
    @Override
    protected void doGet(HttpServletRequest request,
                         HttpServletResponse response)
            throws ServletException, IOException {

        response.setContentType("text/html;charset=UTF-8");

        String input = request.getParameter("number");

        try (PrintWriter out = response.getWriter()) {
            out.println("<!DOCTYPE html>");
            out.println("<html><head><title>Prime Result</title></head><body>");
            out.println("<h1>Prime Number Checker Result</h1>");

            try {
                if (input == null || input.trim().isEmpty()) {
                    out.println("<p>Please enter an integer.</p>");
                } else {
                    int number = Integer.parseInt(input.trim());

                    if (isPrime(number)) {
                        out.println("<h2>" + number +
                                " is a Prime Number.</h2>");
                    } else {
                        out.println("<h2>" + number +
                                " is Not a Prime Number.</h2>");
                    }
                }
            } catch (NumberFormatException e) {
                out.println("<p>Invalid input. Please enter a valid integer.</p>");
            }

            out.println("<p><a href='index.html'>Check another number</a></p>");
            out.println("</body></html>");
        }
    }
}
```
